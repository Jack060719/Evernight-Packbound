## 工作範圍與做法

### r2 必須對齊的交付
地物死亡／營地／讀檔保留同ID；r2換關候選為穩定逐件原子pickup，已領不回滾，尚有領不了才阻擋開新run，不留額外一格。傳給06真實blocked reason，不修改持久重打開關；pending exit與resume gate集中14保存。靠近／點擊同入口，provenance不因場景切換失去，09新表供14唯一抽樣。

怪物死亡經中央sampler產生唯一drop instance，先在地面，不能直接入庫。13處理drop spawn/lifecycle/location與撿取命令，最終發獎抽樣器由14持有。開發以04注入的Sampler/RNG fixture，不另建正式掉落公式。11只播視覺，動畫完成不能改物品所有權。
支援靠近自動撿取與點擊撿取，兩者共用同一pickup transaction／receipt，快速同時觸發也只入庫一次。移轉物品透過07庫存/容量port，餘額與drop已領取狀態一起交14提交。容量不足保留地面物品並新增capacity pause reason，整理後依核准流程恢復，不丟棄、覆蓋或暗換物品。
按01批准的死亡／回營地／換關／結算／重打／刷新／讀檔規則持久化未撿物與位置；交易中斷可恢復，不能重發／少發。出戰場景與物品來源provenance保留，供08收藏與追蹤。06自動重打使用04凍結的待領阻擋與逐件離關ports，存在阻擋時不能自動前進；地上掉落與玩家物件不能同ID同時存在。
對11提供死亡→落地→地面可見→撿取→入庫事件與已處理event序號，讀檔不重播已完成特效／音效，reduced motion不改交易時間或結果。
