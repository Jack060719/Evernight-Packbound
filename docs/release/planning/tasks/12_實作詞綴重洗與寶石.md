## 工作範圍與做法

### r2 必須對齊的交付
詞條只生成／彙總數值：攻擊、連擊次數、暴擊率／傷害、吸血等，不建立詞條trigger或攻速時間制。寶石提供機制effect來源，交05唯一執行。依r2核准表給早期詞條／孔、全部種類／等級／相容／來源／收納，禁止硬套r1白0／紫起孔／4gem／999。升質保留既有詞條石，只補新增槽；所有拆裝、重洗、退石保持原子。

依01核准表與04契約實作取得裝備時的隨機詞綴生成、品質升級保留原詞綴並只補新增槽、整組付費重洗直接覆蓋。不能鎖單條、保留舊結果或二選一。重洗preview明確成本與覆蓋警告；結果、扣款、物件版本與RNG游標以同一transaction plan交14提交，刷新不可免費重抽，快速連點/重試不重複扣料。舊無詞綴物品如何初始化只照01遷移提案，12提供純初始化函式，14負責遷移與保存。
寶石取得時等級固定、可免費拆卸重鑲，不升級不合成；同種同級可堆疊，寶石與材料獨立收納，不占48格或60件倉庫。依核准孔數、相容、容量與stack cap驗證。提供socket、unsocket、replace、reserveReturnMaterialsGems、extendForQualityUpgrade ports；對07合成／拆解與08配裝提供preview與容量驗證，不能自己先扣料。替換同筆退舊扣新，滿容量整筆拒絕。
裝備詞綴／寶石的效果解析給05 combat read model使用；只依04凍結effect IDs，不自加傷害結算。和07各用fixture協作，正式14才接線，無需等待互相分支合併。
