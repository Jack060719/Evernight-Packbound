## 二、核心體驗與範圍

保留卡通粗線條、森林與金葉 UI、A2 圓體字，以及裝備自然輪廓；不改成像素風，也不把遊戲重心變成背包拼圖。保留拖放、旋轉、空間配置與搭配的樂趣，但成長回饋要來自打寶、合成和寵物。

目前約 8 種裝備、2 隻寵物（狼、葉），先利用既有內容。可以參考知名遊戲的定向刷寶、Backpack Battles 的搭配回饋等概念，但須轉化成適合本作的小規模設計，不照抄美術或內容。不新增大型技能樹、數十層關卡、社交、課金、每日限時壓力或離線收益。

## 三、掉落與撿取

- 怪物死亡後，裝備出現在地面，不能立即進背包。支援靠近自動撿取及點擊撿取；兩條路徑共用一次性交易，避免重複領取。
- 必須做出完整掉落與撿取動畫：怪物死亡 → 裝備掉落／落地 → 地面可見 → 靠近／點擊撿取 → 入庫回饋；品質要能辨識。動畫時間與強度先提案，不硬訂秒數；視覺播放與戰鬥模擬、物品所有權分離，避免動畫重播影響獎勵。支援減少動態效果，讀檔不重播已完成的掉落／撿取特效。
- 未撿取掉落持續保留。容量不足時暫停並保留地上物品，讓玩家整理後繼續，不能消失、偷偷覆蓋或強制丟棄。
- 目前約 65% 的統一白裝掉落過密，請依怪物強度／階級降低並分化掉落。後續關卡須有較高品質機會，不能永遠只掉白裝。先提出機率表與每輪預期產量，不自行認定新數值。
- 核實目前只有第 3 層第 5 波有首領；首層保證取得狼的既有規則不變。
- 為掉落設計唯一識別與持久化；明列死亡、回營地、重新整理、讀檔、換層與結算中斷時如何處理。以不丟失、不重複為原則，跨關卡尚未確認的處置先提案。

## 四、背包、倉庫與手動合成

手機主介面上方放已裝備背包，下方放暫存倉庫；選中物品的詳情獨立顯示。倉庫維持 30 件，裝備背包最多 48 格。保留拖放與旋轉，布局要像完成的森林主題遊戲，避免工程面板式堆疊。

新增「整理倉庫」：品質由金、紅、橘、紫、藍、白排序，再依一致的種類順序，同條件維持穩定次序。整理只動倉庫，絕不改裝備位置或攻擊順序。

先給我獨立合成區草圖，保留適用的既有拖曳互動。若我不喜歡，之後再改成純拖曳；不要預先實作兩套替代頁面。

- 裝備與寵物的自動合成 UI、選項及執行邏輯全部移除；舊存檔旗標安全失效，不可保留隱藏自動合成。
- 手動合成維持兩件同種類、同品質；每次只確認一次。成功率維持 90／80／70／60／50%，失敗只消耗材料，沒有保底、累積機率或必成。
- 詞綴不同仍可作材料。升品質保留主裝備原有詞綴及已鑲寶石；因品質提升增加詞綴數或孔位時，如何新增、是否空孔，請明確提案。
- 材料裝備內的寶石須在材料消耗前免費退回；容納不下就阻擋整筆合成，不可先扣料再失敗。
- 寵物保留目前採較高累積經驗值的合成規則，若要改須另提案；出戰寵物不可當材料。
- 成功、失敗、取消與中斷都要原子化處理，不能遺失／複製裝備、寶石或經驗值。

## 五、成長與數值平衡

請核實目前每把武器傷害為「基礎值 × 品質倍率 + 玩家攻擊」，倍率約 1／1.45／2.1／3／4.2／5.8。先前初始條件下，兩把白劍合計 32、一把藍劍 21.4，反映每把附加攻擊與空間效率的取捨，不能只用這個例子直接把高品質數值翻倍。

提出低／中／高進度、相同格數與不同武器數量的比較，包含傷害、存活、合成風險與刷寶速度。讓升品質有合理收益，同時保留低品質多件配置的選擇。合成前顯示主裝備變化、成功率、消耗與可能損失。

已同意方向：可定向取得的區域獎勵、少量有辨識度的裝備效果（可考慮品質門檻）、既有寵物的成長里程碑。請提供具體效果／里程碑／掉落池清單核准，勿把示例直接實作。

## 六、隨機詞綴與寶石

### 隨機詞綴

裝備取得時隨機產生詞綴；刷取材料可重洗整組詞綴，不要求鎖定單條。**重洗結果直接覆蓋，不提供保留舊結果或二選一。** 操作前清楚顯示成本與覆蓋警告，費用、結果、物品版本須同筆提交；生成結果持久化，不能用重新整理反覆抽取或免付費。

先提案各品質詞綴數、可抽池、數值範圍、權重／重複限制、重洗成本及材料來源。既有無詞綴裝備如何遷移、品質提升如何保留與補足詞綴，必須列明，不擅自重抽玩家原有詞綴。

### 寶石

寶石取得時等級固定，可免費拆卸、重複鑲嵌；不做寶石升級或合成。同種類同等級可堆疊，寶石與材料放獨立收納，不占裝備背包或 30 件倉庫。

先提案孔位數量／品質門檻、寶石效果與等級、相容規則、來源／機率、收納容量與堆疊上限；不要隨便塞一個未說明的上限。鑲嵌時正確扣除一顆，拆卸退回一顆；替換、滿容量、快速連點、讀檔與合成均不可複製或遺失。

## 七、營地與戰鬥狀態

名稱使用「營地」。啟動與讀檔進入暫停的營地，不自動開打；原有開始選單可以保留在營地之前。營地可整理、裝備、合成、鑲嵌、重洗、分配玩家屬性／成長點數，以及管理寵物成長。保留未來商店擴充點即可，本版不實作商店交易。

- 「繼續戰鬥」才進入／恢復戰鬥。清楚區分新旅程、已有進度與繼續戰鬥。
- 每層 5 波全部完成後，提供回營地或下一層選擇，不自動前進／重打。第 3 層已是最終層，提供回營地或重打本層的明確選擇，不顯示不可用的下一層。
- 戰鬥中回營地須完整凍結敵人、雙方血量、波次、行動佇列、掉落及計時器；回營地不補血、不重置。回戰鬥接續同一流程。
- 透過換裝、回營地或重新整理不能獲得額外回合；裝備改變最大生命時不可藉此補血，調整公式先提案。
- 既有死亡重試與進入關卡補血機制先保留，若有衝突明確提案；不要誤將營地不補血擴張成移除所有關卡補血。
- 背景停留／重新整理不給離線收益、不偷跑戰鬥或補算回合、不重播音效；結算／選擇畫面中斷後能恢復，不能跳過必要選擇。
