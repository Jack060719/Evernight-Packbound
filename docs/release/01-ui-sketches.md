戰鬥中的↻、裝卸、重洗／鑲石入口都先進入整理暫停，當前impact提交後才准修改；不允許邊出手邊改物。背包與倉庫之間的拖曳不滾走背包；倉庫排序不改位置或出手順序。旋轉只有一個↻，不放角度選單。詳情在獨立區域，不壓成格內長文字。拆解／丟棄放「其他」，鎖定或已裝備時說明原因；不自動挑垃圾、不批次拆解。

48格滿用不等於容量不足；倉庫60且沒待領裝備也不先停。實際新掉裝備放不下才提示，該物保留地上；整理完按「繼續」就沿用重打開關，不再叫玩家開一次。

## 4. 獨立合成區與同一預覽

~~~text
┌──────────────────────────────────┐
│ [‹行囊] 合成     [裝備][寵物]    │
│ [主體：藍劍] ＋ [材料：藍劍]    │
│ → 紫劍，主體ID／詞條／石保留    │
│ 成功80% · 新增1條詞條，孔仍1    │
│ 材料毒牙I退回1顆                │
│ 失敗只消耗材料；退石也照常完成   │
│ [相同品項材料列表，可拖入]       │
│         [查看並確認一次]        │
└──────────────────────────────────┘
~~~

r2藍裝已有一孔，因此上例材料含毒牙I合法；藍→紫新增詞條、不是增加孔。直接拖相同品項同品質裝備到另一件，也開這個同一預覽，不先消耗。一次確認顯示成功／失敗、成本、退回石與主體變化；關閉不抽RNG，連點用同command結果。寵物先顯真正保留的高XP個體，兩方出戰都拒絕，同XP才保留所選主體。

## 5. 詞條、機制石與單件拆解

詳情分「數值詞條」與「寶石機制」兩塊，不混成一長串百分比。詞條沒有攻速；「連擊+1」可展開看一次主擊後追加首主擊15%傷害的真命中，暴擊／吸血照真實命中計。

重洗一次確認：「花費20粉塵，整組直接覆蓋；無法選回舊結果」。不預抽結果，沒有保留舊組按鈕。寶石孔選石可查看相容、固定I/II/III效果；拆／換免費但仍一次原子操作。相同種類最高等級生效的機制要提示，避免誤以為放三顆同石三倍觸發。

拆解一次確認列「單件會消失／取得粉塵X／退回哪些石」；先卸下、鎖定先解鎖。材料與六石三級共18種固定堆疊另外收納，只顯非零數量；本輪推薦無遊戲數量cap，不增任意上限衍生的丟棄石／粉塵功能。任何數量格式錯誤或退回驗證失敗仍整筆拒絕，不先扣材料。
