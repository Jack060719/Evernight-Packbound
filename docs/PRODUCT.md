# 產品規格

狀態：需求已確認，可玩原型已建立。本文是首版玩法與範圍的主要依據；驗收進度見 [開發路線](../ROADMAP.md)，精確數值仍需實際遊玩調整，不將自動測試視為平衡完成。

## 1. 遊戲目標與範圍

製作供個人遊玩的手機瀏覽器遊戲。主要樂趣是自動刷怪後，透過裝備空間效率、攻守取捨、寵物搭配與合成決策提升戰力。

核心循環：**刷怪 → 取得裝備、角色經驗與寵物蛋 → 整理背包、分配成長點、合成 → 挑戰更高樓層**。

| 項目 | 首版範圍 |
| --- | --- |
| 平台 | 手機瀏覽器，直向介面，繁體中文；桌面可輔助測試 |
| 遊戲模式 | 單人、單一永久角色、本機單一存檔 |
| 關卡 | 3 層，每層 5 波 |
| 裝備 | 8 種品項，6 階品質 |
| 靈寵 | 星焰狐與芽葉靈，各有品質、等級與經驗 |
| 敵人 | 2 種普通怪物、1 種頭目 |
| 掛機 | 僅遊戲顯示於前景時運作，無離線收益 |
| 影音 | 少量復古奇幻美術、一首循環背景音樂、必要遊戲音效 |

首版不加入帳號、雲端同步、商店、職業、多人或其他養成系統。

## 2. 戰鬥與關卡

- 角色維持在畫面左側；背景向左捲動，表現角色持續向右前進。
- 遇到一波敵人時停止前進並自動戰鬥，整波消滅後繼續前進。
- 採全自動回合：武器依背包位置由上至下、同列由左至右，各攻擊一次；接著結算到期的護符與出戰靈寵，最後存活怪物依序各攻擊一次。玩家不必每回合按確認。
- 武器攻擊最前方敵人，沒有武器時每回合徒手攻擊一次。每個動作分開演出，介面顯示目前回合與行動中的裝備。
- 每波從第 1 回合開始；再生護符在第 3、6、9……回合回血。此配置定位為長戰續航，短戰不保證觸發。
- 同一回合已行動的物品不會因整理或讀檔再次行動；本回合新裝入的武器與換上的靈寵，下回合才加入行動。被移除的物品略過。
- 首版以第三層最後一波作為頭目戰，其餘波次由普通怪物組成。
- 通關自動解鎖並前往下一層；可選擇重刷已解鎖樓層。第三層通關後重刷第三層。
- 角色死亡後短暫倒下，再滿血回到當層第一波；保留角色等級、裝備、寵物、背包擴充與已取得物品。
- 進入或重新開始樓層時恢復生命；波與波之間保留剩餘生命，行進時不額外回血。武器清光怪物後，仍結算當回合到期的輔助效果，再前進下一波。

## 3. 背包與裝備

### 尺寸與放置

全文尺寸皆以「列 × 欄」表示：列為上下方向，欄為左右方向。

| 狀態 | 尺寸 | 總格數 |
| --- | --- | --- |
| 起始背包 | **4 列 × 5 欄** | **20 格** |
| 最大背包 | **6 列 × 8 欄** | **48 格** |

- 背包呈橫向長方形；手機整體介面仍採直向。
- 起始開啟矩形區域，平常只顯示已解鎖格，格子隨可用畫面放大。不規則缺角保持透明，保留真實格子位置。
- 只有擴充模式暫時顯示與已解鎖區域共邊相鄰的「＋」，選擇其中一格解鎖；不常駐顯示全部 48 格。
- 占格配合裝備的自然外形：盾牌為完整 2 列 × 2 欄，筆直法杖為 4 列 × 1 欄。不得為了拼格把盾牌切缺角、把直桿折彎，或拉伸圖像。可整件旋轉；不能重疊、越界或占用未解鎖格。
- 所有放入背包的裝備共同生效，沒有相鄰加成，也沒有另外的傳統裝備欄。
- 未放入背包的裝備留在待整理區，不提供戰鬥能力。

### 裝備品項

| 品項 | 作用 |
| --- | --- |
| 短劍 | 每回合攻擊一次 |
| 匕首 | 每回合攻擊一次，占格較小 |
| 弓 | 每回合攻擊一次 |
| 法杖 | 每回合攻擊一次 |
| 護甲 | 提供生命或防禦能力 |
| 盾 | 提供防禦能力 |
| 攻擊戒指 | 提高攻擊能力 |
| 再生護符 | 每 3 回合回血 |

各品項的占格、回合週期、能力與品質倍率集中於內容資料。升階只改變品質與能力，不改變品項或占格形狀。攻擊加點與小型武器的效率需一起驗證，不能直接沿用秒數冷卻版本的傷害數值。

### 手機整理操作

- 進入整理模式時暫停戰鬥。
- 支援拖曳與點選物品後點目的格放置。選取時只提供一個「↻」旋轉入口，不顯示角度；已裝備物品能原地合法旋轉時立即套用。
- 非法放置回到原位置，且不消耗或複製物品。
- 一件裝備以完整、等比例圖像跨越實際占用格，配合連續占格底板；不再以首格小圖與其餘白點表示。品質使用醒目色框、淡色底板與「白／藍／紫／橘／紅／金」單字角標；選取、出手與拖曳合成不覆蓋品質色，旋轉只轉圖像，角標維持直立。詳細能力按需開啟，合成卡顯示完整品質名稱。
- 調整裝備不補滿生命；最大生命降低時，當前生命不得高於新上限。

## 4. 角色成長

- 擊殺怪物獲得經驗，角色升級後取得 **1 成長點**。
- 成長點可用於提高攻擊或生命，也可累積 **2 點擴充一格背包**。
- 升級不強迫中斷戰鬥，玩家可保留未使用點數，稍後在整理時分配。
- 屬性與背包使用同一種點數，形成即時戰力與裝備容量的取捨。
- 等級經驗曲線與每點屬性的實際增幅，在原型平衡階段設定並驗證。

## 5. 寵物

- 擊殺怪物可能掉落寵物蛋，蛋自動孵化成寵物，不另外管理蛋的庫存。
- 首層首次通關保證取得一顆星焰狐靈蛋；之後星焰狐與芽葉靈皆可由刷怪隨機取得。
- 每隻寵物獨立保存品質、等級與累積經驗，允許持有多隻同種寵物。
- 一次出戰一隻，使用獨立寵物欄，不占背包格子；寵物不會受傷或死亡。
- 星焰狐以每回合攻擊支援；芽葉靈每 3 回合替角色回血。兩者採有辨識度的像素靈寵造型，保留攻擊與治療兩種原型職責。
- 出戰寵物取得完整擊殺經驗，不扣除角色獲得的經驗；未出戰寵物不取得戰鬥經驗。
- 等級與品質共同強化寵物能力，死亡重試與讀檔都保留養成。
- 切換出戰寵物與合成在整理模式操作。

## 6. 合成

### 材料與成功率

裝備需為同品項、同品質；寵物需為同物種、同品質。兩份材料嘗試升為一份高階產物。

| 品質升階 | 成功率 |
| --- | --- |
| 白 → 藍 | 90% |
| 藍 → 紫 | 80% |
| 紫 → 橘 | 70% |
| 橘 → 紅 | 60% |
| 紅 → 金 | 50% |

- 金色為最高品質，不能再合成。
- 成功：主體升一階，消耗另一份材料，保留品項或物種。
- 失敗：主體維持原狀，只消耗另一份材料。
- 寵物以兩者中累積經驗較高者為主體；成功或失敗均保留該經驗。被消耗寵物的經驗不轉移。
- 手動裝備合成支援背包與待整理區之間互拖；拖到同品項、同品質裝備上，先開啟確認，再執行。目標物品為保留主體，維持其位置，拖來的物品作為消耗材料。
- 自動合成仍只使用待整理區裝備；寵物合成仍排除出戰寵物。合成造成能力改變時重新限制生命上限，不補血。
- 手動合成先顯示材料、產物、成功率與失敗代價，再由玩家執行。

### 自動合成

- 裝備、寵物各自提供開關，預設皆關閉。
- 各自設定「最高產出品質」，預設為藍色。例如上限藍色時，只會嘗試白合藍。
- 從低品質往高品質處理可用材料，直到沒有符合條件的配對；不得超過指定的最高產出品質。
- 成功率、失敗損失與主體保留規則，與手動合成完全相同。
- 新掉落處理時執行已開啟的自動合成，以釋放容量。

## 7. 戰利品容量與中斷

- 裝備待整理區最多 **30 件**，背包內裝備另計。
- 寵物列表最多 **30 隻**，包含目前出戰寵物。
- 先處理掉落與已開啟的自動合成；若仍無法收入新物品，保留本次尚未收入的掉落並暫停遊戲。
- 容量不足時顯示原因，等待玩家整理；不丟棄新掉落，也不自動淘汰既有物品。
- 整理出空間後收入待領掉落，再繼續戰鬥；待領資料同樣寫入存檔。
- 提供丟棄裝備、放生未出戰寵物的操作，執行前確認。

## 8. 介面、美術與音訊

### 介面與美術

- 開啟遊戲先顯示獨立開始畫面，素材就緒後可開始／繼續；進場、換層及倒下重試有簡短轉場，轉場期間不推進模擬。
- 直向介面上方顯示戰場、樓層、波次與血量；下方顯示背包及整理入口。
- 遊戲常駐畫面只顯示必要資訊與已裝備行囊預覽；待整理物品、成長、寵物、合成、設定及說明放在按需開啟的管理面板，裝備詳情選取後才顯示。
- 關閉管理面板只解除該面板造成的整理暫停，保留手動、背景與容量暫停。可從選單返回開始畫面並保留旅程，進度不重置。
- 美術改為明亮森林奇幻：暖陽、草綠與木色，統一像素輪廓，角色約 3 頭身、稍微 Q 版；降低壓抑感，角色、怪物、裝備與背景使用同一風格。
- 使用 `agent-sprite-forge` 對應的 `generate2dsprite` 與 `generate2dmap` 流程，製作少量角色、怪物、寵物、物品圖示與可捲動背景。
- 原型先用簡單動作、受擊閃爍與必要特效表達戰鬥；保留素材原圖、提示詞及處理結果。

### 音樂與音效

- 音樂使用另行合成的柔和暖色和弦與鐘聲，配合森林冒險氣氛；音效維持清楚、短促，不使用外部遊戲錄音。
- 首版包含 **一首可循環的背景音樂**。
- 音效需涵蓋攻擊、受擊、死亡、掉落、升級、寵物技能、合成成功、合成失敗與介面操作；相容事件可共用適合的音效。
- 音樂與音效分別提供音量及靜音控制，設定寫入本機存檔。
- 玩家點選開始遊戲後啟動音訊；切到背景時暫停，返回後依遊戲狀態與音量設定恢復。
- 整理或容量不足而暫停戰鬥時，不繼續產生戰鬥音效；介面與合成音效仍可依操作觸發。
- 限制同時播放的音效數量，避免多武器與多怪物造成密集重疊。

## 9. 保存與原型成功條件

- 本機保存角色、背包、裝備、寵物、關卡、戰鬥、待領掉落、自動合成及音訊設定。
- 切到背景時保存並停止模擬，返回不補算離開期間的時間；讀檔恢復保存的戰鬥狀態並先保持暫停。
- 合成材料消耗與結果完整保存，刷新不得造成物品重複或只記錄一半結果。
- 玩家可完整體驗「刷取 → 整理 → 合成 → 變強 → 推進」循環；同等級不同配置能明確改變輸出或生存表現。
- 在 360、390、430 像素寬的直向畫面能完成整理、擴格、寵物切換與合成，最大背包不造成整頁水平溢出。
- 桌面模擬測試與手機實機驗證分別記錄，不把模擬結果當成實機通過。

細部實作與驗收順序見 [開發路線](../ROADMAP.md)。

## 10. 正式版後續方向

- 新旅程加入簡短介紹與逐步取得裝備的開局，不沿用目前為測試配裝而提供的整套起始裝備。本次改版保留現有原型進度，不清空存檔。
- 裝備效果、怪物機制與關卡一起設計，讓火力、續航、防禦等配置各有適合的情境，避免只比較品質或單一最高數字。具體流派與完整平衡仍待後續決策與遊玩驗證。
- 技能系統留待正式版討論，本輪不加入。
