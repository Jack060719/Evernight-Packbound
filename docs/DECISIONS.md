# 決策紀錄

更新日期：2026-10-04。以下為首版方向與原型實作選擇；功能驗收以 [開發路線](../ROADMAP.md) 的實測紀錄為準。

## 1. 已確認的產品選擇

| 項目 | 決策 | 取捨與目的 |
| --- | --- | --- |
| 首次交付 | 先做 3 層玩法原型 | 先驗證配裝、合成與爬塔循環，再擴充內容 |
| 平台 | 手機瀏覽器、直向，上戰鬥下背包 | 方便手機直接遊玩與整理 |
| 戰鬥 | 左側角色向右前進，遇到一波敵人就停下戰鬥 | 以自動行進與波次呈現刷怪 |
| 成長保存 | 角色、裝備、寵物與背包永久保留 | 死亡只重新挑戰當層，不重置養成 |
| 掛機範圍 | 只在前景自動刷怪 | 離開、鎖屏或關閉後不計算收益 |
| 背包玩法 | 不同形狀拼放，可旋轉，無相鄰加成 | 策略集中在空間與裝備效果搭配 |
| 背包尺寸 | 起始 4 列 × 5 欄，共 20 格；最大 6 列 × 8 欄，共 48 格 | 橫向背包；取代先前方形背包提案 |
| 多武器 | 每回合依背包位置逐件攻擊一次，再結算輔助與敵方行動 | 讓出手順序清楚，取代獨立秒數冷卻 |
| 升級選擇 | 屬性與擴格共用成長點 | 讓即時能力與裝備容量互相取捨 |
| 寵物出戰 | 獨立寵物欄，一次一隻，不會死亡 | 透過攻擊或治療支援配裝 |
| 寵物取得 | 刷怪掉蛋，允許同種多隻 | 重複寵物保留為合成材料 |
| 重複寵物 | 同物種、同品質合成升階 | 取代重複蛋直接轉經驗的提案 |
| 合成材料 | 裝備同品項同品質，寵物同物種同品質 | 成功產物的品項及物種可預期 |
| 合成失敗 | 保留主體，只消耗另一份材料 | 高階有失敗代價，但不一次失去兩份養成 |
| 合成操作 | 手動及可開啟的自動合成 | 自動模式仍遵守相同風險與品質上限 |
| 容量不足 | 保留本次掉落並暫停，等待整理 | 避免略過新裝備或自動丟棄既有裝備 |
| 美術工具 | `agent-sprite-forge` 對應的 `generate2dsprite`、`generate2dmap` | 製作少量符合原型需求的素材 |
| 視覺風格 | 明亮森林、暖陽草綠木色、微 Q 版像素 | 降低壓抑感，統一角色、場景、裝備與介面 |
| 音樂與音效 | 另行合成的柔和鐘聲與暖色和弦 | 配合森林冒險，避免沉重氛圍 |

## 2. 合成機率

| 升階 | 成功率 |
| --- | --- |
| 白 → 藍 | 90% |
| 藍 → 紫 | 80% |
| 紫 → 橘 | 70% |
| 橘 → 紅 | 60% |
| 紅 → 金 | 50% |

金色為最高品質。成功後主體升階、材料消耗；失敗後主體不變、材料消耗。寵物合成保留兩者中較高的累積經驗，被消耗者的經驗不轉移。

## 3. 採用的原型預設

- 3 層、每層 5 波，8 種裝備、2 種寵物、2 種普通怪物、1 種頭目；第三層最後一波作為頭目戰。
- 通關自動前往下一層，可重刷已解鎖樓層；最後一層通關後重刷該層。
- 死亡後滿血回到當層第一波；每次進入樓層恢復生命，波間保留剩餘生命。
- 每次角色升級給 1 成長點；2 點解鎖一格與已開啟區域共邊相連的背包格。
- 星焰狐提供攻擊，芽葉靈提供回血。出戰靈寵取得完整擊殺經驗，不扣角色所得經驗；首層首次通關保證一顆星焰狐靈蛋。
- 裝備待整理區上限 30 件，背包內裝備另計；寵物列表上限 30 隻，包含出戰者。
- 自動合成的裝備與寵物開關各自設定、預設關閉；最高產出品質各自預設藍色。
- 手動裝備合成包含背包與待整理區，可互相拖曳開啟確認；目標是保留主體，拖來的是材料。自動合成仍排除背包內裝備，由低品質往高品質處理；寵物合成仍排除出戰者。
- 首版一首循環背景音樂；音樂與音效分開調整音量及靜音，設定永久保存。
- TypeScript、Vite、Phaser、HTML/CSS 與瀏覽器本機單一存檔；繁體中文、單人、單一角色。

以上為已採用的原型預設，後續更動應同步更新 [產品規格](PRODUCT.md) 與相關文件。

## 4. 原型階段待設定與驗證

已採用的首輪數值集中於 `src/game/content.ts` 與 `src/game/engine.ts`，可調整但不改變既定玩法：

- 基礎生命 100、攻擊 4；每點攻擊 +2、生命上限 +15。等級累積經驗門檻為 `15 × 等級 × (等級 − 1)`，角色與寵物共用。
- 品質倍率依白至金為 1、1.45、2.1、3、4.2、5.8；實際合成機率仍依前表。
- 原型起始配裝為短劍、盾與再生護符，待整理區有匕首與兩把短劍；無武器時每回合徒手攻擊一次。正式版再設計介紹與循序取得裝備的開局，本次不清除既有進度。
- 擊殺普通怪物及頭目使用同一掉落流程：65% 裝備、8% 靈寵蛋，蛋的兩物種機率相同。第一層首次通關星焰狐靈蛋另行保證且只發一次。
- 行進 2 秒，死亡等待 2.5 秒重試；規則採 20 Hz 固定步進。背景返回與讀檔均要求玩家點選繼續。
- 圖像採獨立生成立繪與透明圖示，動作由畫面位移及受擊效果表達；音訊為程式合成的原創 32 秒循環曲及 9 種事件音效，同時播放上限 6 個。
- 依介面簡化需求，改為獨立開始畫面、精簡遊戲畫面及按需開啟的管理面板。說明與細部能力不常駐；開始畫面／轉場不推進戰鬥，畫面切換不重置存檔。

仍需驗證與調整：

- 各裝備的精確占格、每回合傷害／治療、能力與品質倍率，以及角色、靈寵的經驗曲線。
- 怪物強度、波次組成、隨機掉落率與平均通關時間。
- 音樂與音效的實際聽感、長時間播放舒適度及不同手機的表現。
- 手機實機的效能、觸控、鎖屏與音訊恢復；桌面模擬結果不代表實機通過。

這些項目在既定玩法範圍內調整，不增加額外系統。開發順序與驗收見 [開發路線](../ROADMAP.md)。

## 5. 本輪使用者確認（2026-10-04）

- 全自動回合順序：背包由上至下、同列由左至右的武器各一次 → 到期護符／靈寵 → 存活怪物各一次。每波重新計數，護符第 3、6、9 回合生效，定位為長戰續航。
- 保留單一旋轉按鈕，不顯示角度；合法的原地旋轉立即套用。
- 手動拖曳合成可跨背包與待整理區，先確認機率及失敗代價，目標保留位置。
- 平常只顯示已解鎖格，背包放大，裝備以完整跨格圖顯示；擴格模式才顯示相鄰「＋」。
- 美術採明亮森林像素微 Q 版，靈寵為星焰狐與芽葉靈。
- 技能、新手介紹、正式版從少量裝備起步，以及裝備／怪物／關卡一體考量的完整流派平衡，留待後續。

後續外形修正：占格應配合裝備本身，不能反過來把裝備拗成拼圖。盾牌恢復完整矩形（2×2 格），法杖恢復直桿（4×1 格，維持 4 格成本），圖像等比縮放、整件旋轉。舊存檔因新占格發生衝突時重新安置，無法安置者保留至待整理或待領區，不改戰鬥回合進度。
