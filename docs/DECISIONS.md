| 合成失敗 | 保留主體，只消耗另一份材料 | 高階有失敗代價，但不一次失去兩份養成 |
| 合成操作 | 手動及可開啟的自動合成 | 自動模式仍遵守相同風險與品質上限 |
| 容量不足 | 保留本次掉落並暫停，等待整理 | 避免略過新裝備或自動丟棄既有裝備 |

| 視覺風格 | 早期《天堂》的陰暗中世紀奇幻、低彩度與石造介面 | 統一角色、場景與介面氣氛 |
| 音樂與音效 | 另外製作相近風格音訊 | 參考早期《天堂》的氣氛與聲音質感 |

## 2. 合成機率

| 升階 | 成功率 |
| --- | --- |
| 白 → 藍 | 90% |
| 藍 → 紫 | 80% |
| 紫 → 橘 | 70% |
| 橘 → 紅 | 60% |
| 紅 → 金 | 50% |

金色為最高品質。成功後主體升階、材料消耗；失敗後主體不變、材料消耗。寵物合成保留兩者中較高的累積經驗，被消耗者的經驗不轉移。

## 3. 採用的原型預設

- 3 層、每層 5 波，8 種裝備、2 種寵物、2 種普通怪物、1 種頭目；第三層最後一波作為頭目戰。
- 通關自動前往下一層，可重刷已解鎖樓層；最後一層通關後重刷該層。
- 死亡後滿血回到當層第一波；每次進入樓層恢復生命，波間保留剩餘生命。
- 每次角色升級給 1 成長點；2 點解鎖一格與已開啟區域共邊相連的背包格。
- 狼提供攻擊，治療精靈提供回血。出戰寵物取得完整擊殺經驗，不扣角色所得經驗；首層首次通關保證一顆狼蛋。
- 裝備待整理區上限 30 件，背包內裝備另計；寵物列表上限 30 隻，包含出戰者。
- 自動合成的裝備與寵物開關各自設定、預設關閉；最高產出品質各自預設藍色。
- 手動與自動合成都排除背包內裝備與出戰寵物；自動模式由低品質往高品質處理。
- 首版一首循環背景音樂；音樂與音效分開調整音量及靜音，設定永久保存。
- TypeScript、Vite、Phaser、HTML/CSS 與瀏覽器本機單一存檔；繁體中文、單人、單一角色。

以上為已採用的原型預設，後續更動應同步更新 [產品規格](PRODUCT.md) 與相關文件。

## 4. 原型階段待設定與驗證

以下尚未經實作測試，不把具體值描述成既定結果：

- 各裝備的精確占格、攻擊冷卻、能力與品質倍率，以及角色、寵物的經驗曲線。
- 怪物強度、波次組成、隨機掉落率與平均通關時間。
- 原型素材的實際圖像、音樂、音效檔案及事件對應；音效同時播放數量的具體上限。
- 套件相容版本與手機實機的效能、觸控及音訊表現。

這些項目在既定玩法範圍內調整，不增加額外系統。開發順序與驗收見 [開發路線](../ROADMAP.md)。
