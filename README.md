# 永夜行囊｜Evernight: Packbound

以手機瀏覽器遊玩的單人自動戰鬥遊戲。角色刷怪取得裝備、經驗與寵物蛋，玩家透過有限背包中的裝備配置、角色成長、寵物搭配與合成，挑戰更高樓層。

核心循環：**自動刷怪 → 取得戰利品 → 整理背包與合成 → 強化角色及寵物 → 推進樓層**。

## 目前狀態

已建立 **可在瀏覽器遊玩的三層原型**：自動戰鬥、背包配裝、成長、寵物、合成、容量暫停與本機存檔均已串接，並整合原創生成美術與合成音訊。手機實機驗收及長期平衡仍待進行。

## 啟動

使用 Node.js 22.12 以上版本；本機驗證環境為 Windows、Node.js 24.20.0。

```powershell
npm.cmd ci
npm.cmd run dev
```

開啟 `http://localhost:5173`。手機與電腦連上相同區域網路後，開啟終端列出的 Network 網址（例如 `http://192.168.1.10:5173`）；電腦防火牆需允許此開發伺服器連線。在其他作業系統可將 `npm.cmd` 改為 `npm`。

```powershell
npm.cmd test             # 規則、固定步進與存檔測試
npm.cmd run test:browser # 先啟動 dev；使用本機 Chrome 執行手機尺寸桌面模擬
npm.cmd run build        # 型別檢查及產生 dist/
npm.cmd run preview      # 預覽建置產物，預設 http://localhost:4173
```

`dist/` 可放到靜態網站主機，支援子路徑；請透過 HTTP 開啟，勿直接雙擊 HTML。瀏覽器測試截圖與結果位於 `test-results/`，不納入版本控制。

## 操作

1. 開啟遊戲先進入開始畫面，素材就緒後點選開始／繼續旅程。進場、換層及倒下時有短轉場；開始畫面與轉場不推進戰鬥。
2. 遊戲畫面僅保留戰場、血量、回合／波次和行囊。背包放大且只顯示已解鎖格，一件裝備以完整圖像跨越占格。點「行囊」整理時暫停；可拖曳，也可點選後點目的格，旋轉只保留一個「↻」。
3. 武器依背包由上至下、同列由左至右，各攻擊一次；接著輪到到期護符與靈寵，最後存活怪物各行動一次。每波重新計回合，再生護符每 3 回合回血。
4. 點「成長」分配攻擊、生命，或用 2 點擴充相鄰格；點「旅伴」切換灰鬃狼或芽葉靈。首次通過第一層會保證取得灰鬃狼。
5. 把同品項、同品質裝備拖到另一件上即可開啟合成確認，背包與待整理區都適用；放上的目標保留，拖來的材料消耗。確認視窗顯示成功率及失敗代價，自動合成仍只處理待整理裝備。
6. 關閉管理面板返回遊戲；若原本手動暫停、切過背景或容量不足，關閉面板不會擅自恢復戰鬥。容量滿時掉落會保留，整理出空間即可繼續。
7. 遊戲選單可調整設定、查看說明或返回開始畫面。返回開始畫面只暫停並保存旅程，不會清除進度。

原型初始行囊仍放入短劍、盾牌與再生護符，待整理區提供匕首及兩把短劍，方便驗證配裝與合成。沒有武器時每回合徒手攻擊一次。正式版的簡短介紹、從少量裝備起步及裝備／怪物／關卡的流派平衡另行設計；本次不重置原有進度。

存檔屬於**目前瀏覽器及網站網址**；換裝置、換網址或清除網站資料不會沿用進度。切換背景、關閉頁面及重要操作會保存，另每 5 秒保存戰鬥；返回前景或讀檔後需點選繼續，不補算離線收益。

回合版使用 v2 存檔。舊 v1 會保留成長、裝備、靈寵、背包及待領物品，從目前樓層第 1 波轉入新規則；原始 v1 存檔保留。v2 之後可續接目前回合動作，讀檔不會重複出手。

## 首版原型

- 手機直向操作，上方戰鬥、下方背包；角色在左側向右前進，遇到一波怪物就停下交戰。
- 3 層、每層 5 波，包含 8 種裝備、2 種寵物、2 種普通怪物與 1 種頭目。
- 背包初始 **4 列 × 5 欄，共 20 格**，最多 **6 列 × 8 欄，共 48 格**；裝備有不同形狀，可以旋轉。
- 占格配合自然外形：圓盾 2×2 格、直法杖 4×1 格；完整圖像等比顯示，不為拼格而折彎或切缺角。
- 背包內裝備共同生效，武器依位置逐件自動行動，之後由怪物行動。角色升級點數用於攻擊、生命或擴充背包。
- 寵物蛋由刷怪取得，一次帶一隻寵物協戰；裝備與寵物皆可由白色逐階合成至金色。
- 提供手動及可選擇開啟的自動合成；容量不足時保留本次掉落並暫停，等待整理。
- 成長永久保留；死亡後從當層第一波重試。只在遊戲顯示於前景時掛機，不提供離線收益。
- 採用已確認的「04 粗線卡通＋C 金色花葉介面」：森林遺跡、鮮明色塊與厚實輪廓，搭配 A2 減細圓角字體。保留原有合成音訊。

## 實作與素材

使用 TypeScript、Vite、Phaser，搭配 HTML/CSS 操作介面與 `localStorage` 單一版本存檔。套件精確版本記錄於 `package.json` 與 `package-lock.json`；遊戲規則放在 `src/game/`，與畫面及 DOM 分離。

圖像使用內建 `image_gen` 流程製作，卡通原圖、提示詞與輸出規格位於 `assets-source/cartoon-c/`，執行用檔案位於 `public/assets/`。`node scripts/process-art.mjs` 可重做透明裁切與背景接縫處理。角色採獨立靜態圖配合位移、起伏及受擊效果，尚非逐格動畫。戰場維持 480 × 264 邏輯座標，使用 960 × 528 畫布與平滑縮放。

字體採用使用者確認的 A2：粉圓原生筆畫、關閉模擬粗體，大標題只保留輕微描邊與陰影。網站自帶 `public/fonts/round.woff`，來源與授權一併保留；戰鬥數字及頭目標籤也使用同一字體。

設計過程保存在[美術圖庫](output/art-exploration/round-03/index.html)、[實際遊戲前後比較](output/game-art-preview/index.html)與 [A／A2 字體對照](output/font-preview/round-refined.html)。字體比較是當時的實際遊戲截圖；目前可玩版本已採 A2。原型回合規則、存檔格式、占格與音訊不因這次美術改動而改變。

音訊為另行合成的 32 秒循環曲及 9 種事件音效，沒有使用原遊戲錄音。`node scripts/generate-audio.mjs` 可重建，實際同時播放的音效上限為 6 個。所有遊戲影音均由本專案供應，不依賴遠端字型或素材服務。

驗證範圍與待辦見 [開發路線](ROADMAP.md)。桌面觸控模擬不能代替 Android／iOS 實機的觸控、音訊、鎖屏及效能驗收。
